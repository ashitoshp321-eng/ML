Core Concept

What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence (AI) focused on building systems that learn from data, identify patterns, and make decisions with minimal human intervention. Instead of being explicitly programmed with static rules, ML algorithms use mathematical models to find hidden structures in historical training inputs and make inferences on unseen observations.

Supervised Learning

Supervised learning occurs when algorithms are trained on labeled datasets containing both the input features and the correct target label. The model learns a mapping function to predict the target for new inputs.

  • Regression: Predicts continuous numerical values (e.g. house pricing).
  • Classification: Predicts discrete categorical tags (e.g. flower species).

Unsupervised Learning

Unsupervised learning occurs when models analyze unlabeled datasets. The algorithm attempts to discover underlying structures, mathematical groupings, or dimensions without explicit supervision.

  • Clustering: Grouping data elements based on feature similarity (e.g. customer segments).
  • Dim Reduction: Compressing high-dimensional feature counts (e.g. PCA component projections).
