Frequently Asked Questions

Head to the Firebase Console, navigate to Project Settings -> Service Accounts, select Python, and generate a new private key. Download this JSON file, rename it to firebase-credentials.json, and place it directly in the root directory of this project. The database layer will automatically detect it and transition from local JSON simulation to live Cloud Firestore.

The platform currently supports standard comma-separated value (CSV) files. Make sure the file has headers in the first row. Categorical feature columns are automatically converted using One-Hot encoding, and numerical values can be scaled.

Serialized estimators are saved as .pkl binary files in the saved_models/ folder. Generated CSV metric charts and ReportLab PDF audits are written to the reports/ folder. You can download these directly from the training results panel.
